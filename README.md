# Mobile Sales Dashboard – Power BI

## 📌 Project Overview

An interactive Power BI dashboard designed to analyze mobile
sales performance and identify important sales trends.

## 🎯 Objectives

- Analyze total sales
- Identify top-performing products
- Analyze sales trends
- Compare sales across locations
- Track key business KPIs

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Features

- KPI Cards
- Sales Trend Analysis
- Product Analysis
- Location Analysis
- Interactive Slicers
